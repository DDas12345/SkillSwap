# SkillSwap Campus

**Learn something new. Teach something you know.**

## Project Overview

SkillSwap Campus is a community-based skill exchange platform designed for college students. It aims to connect students who want to learn new skills with peers who can teach them.

The platform encourages collaborative learning by allowing students to exchange knowledge, discover compatible learning partners, and develop new abilities without requiring payment for every learning interaction.

## Problem Statement

College students possess diverse skills, such as programming, graphic design, photography, communication, and creative writing. However, finding the right people to learn from or opportunities to share their knowledge can be challenging.

SkillSwap Campus aims to address this problem by creating a centralized platform for peer-to-peer skill sharing within college communities.

## Proposed Solution

The platform will allow students to create profiles, list the skills they can teach, specify the skills they want to learn, and discover potential learning partners.

A skill-matching system will help identify students with compatible teaching and learning goals. Students will be able to send exchange requests and manage their learning interactions through a personalized dashboard.

## Planned Features

- Student registration and login
- Student profiles and skill listings
- Search and filter functionality
- Skill exchange requests
- Mutual skill-matching recommendations
- Dashboard for managing exchanges
- Learning history and feedback

## Technology Stack

- **Frontend:** React, JavaScript, CSS, Vite
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Version Control:** Git and GitHub

## Project Goal

The goal of SkillSwap Campus is to make peer-to-peer learning more accessible, promote collaboration among college students, and build a community where everyone has something valuable to teach and something new to learn.
