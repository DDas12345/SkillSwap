# SkillSwap Campus

**Learn something new. Teach something you know.**

## Project Overview

SkillSwap Campus is a community-based skill exchange platform designed for college students. It provides a space where students can share their knowledge, discover new skills, and connect with peers who have complementary learning goals.

The platform aims to encourage collaborative learning by enabling students to teach skills they already know in exchange for learning something new from others.

## Problem Statement

College students possess a wide range of skills, including programming, graphic design, photography, communication, and more. However, they may struggle to find peers who can help them learn new skills or opportunities to share their own knowledge.

SkillSwap Campus aims to bridge this gap by creating an accessible platform for peer-to-peer learning and skill exchange within college communities.

## Proposed Solution

SkillSwap Campus will allow students to create profiles, list the skills they can teach, specify the skills they want to learn, and discover compatible learning partners.

The platform will focus on mutual learning, collaboration, and building a supportive campus community where knowledge can be exchanged without requiring payment for every learning interaction.

## Planned Features

- Student registration and login
- Student profiles and skill listings
- Search and filtering for available skills
- Exchange requests between students
- Skill-based matching and recommendations
- A dashboard to manage learning exchanges
- Exchange history and feedback

## Technology Stack

- **Frontend:** React, JavaScript, CSS, Vite
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Version Control:** Git and GitHub

*The technology stack and features listed above describe the intended project scope and will be updated as implementation progresses.*

## Project Goal

The goal of SkillSwap Campus is to make peer-to-peer learning more accessible, encourage collaboration among students, and create a community where everyone has something valuable to teach and something new to learn.
